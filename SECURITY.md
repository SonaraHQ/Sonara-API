# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem.
Report it privately from the [Security tab](https://github.com/SonaraHQ/Sonara-API/security/advisories/new) of the repository instead.

Include the affected version, the steps to reproduce and the impact you expect.
You will get an answer as soon as possible, and credit in the release notes if you want it.
